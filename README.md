# apisdkgen - Go API SDK generator

[![Go Reference](https://pkg.go.dev/badge/github.com/maruel/apisdkgen.svg)](https://pkg.go.dev/github.com/maruel/apisdkgen)

Generate typed TypeScript, Kotlin, and Swift SDKs and an API reference from Go
DTOs and route definitions.

Define an `apispec.Config` for each API version, then register the versions in
one generated package from your application's generation command:

```go
api := apisdkgen.NewAPI("sdk/voicegateway", "VoiceGatewaySDK",
    apisdkgen.NewVersion("v1", "voicegateway/api/v1", v1.SDKAPI()),
    apisdkgen.NewVersion("v2", "voicegateway/api/v2", v2.SDKAPI()),
)
err := api.Generate()
```

The package name is an identifier used for Swift products and targets. Version
names use `v` followed by a positive major number. Each version supplies its own
Kotlin package namespace through `apispec.Config.KotlinPackage`. Namespaces must
be distinct across versions. Typed version specifications may use different
error-code types.

Every package has one standard layout:

```text
sdk/voicegateway/
  API.v1.md
  API.v2.md
  ts/package.json
  ts/tsconfig.json
  ts/v1/
  ts/v2/
  kotlin/build.gradle.kts
  kotlin/settings.gradle.kts
  kotlin/src/main/kotlin/<package namespace>/
  swift/Package.swift
  swift/Sources/VoiceGatewaySDKV1/
  swift/Sources/VoiceGatewaySDKV2/
```

All languages are generated by default. For an API that uses TypeScript-only
features such as query request mapping, set `api.Languages` to
`[]apisdkgen.Language{apisdkgen.TypeScript}`. API references are always generated.

The TypeScript package exports source files through versioned subpaths such as
`voicegatewaysdk/v1/api.gen`; check it with `tsc --project ts`. The generated
package is private; publishing and release versioning belong to consumers.
The Kotlin JVM module builds standalone with Gradle and Java 21, or as a Gradle
subproject using the host's Kotlin plugins and repositories. Swift Package
Manager exposes a product per version for macOS 13 and iOS 16 or later; generated
Swift clients target Apple Foundation networking APIs.

The entire output directory belongs to the generator. Do not store handwritten
files inside it. `API.Generate` prepares every version and package manifest
before recursively clearing the directory and writing the result. Preparation
errors preserve existing output; publication errors can leave incomplete output,
so fix the cause and rerun generation. Separate API packages must use separate,
non-overlapping output directories.

`API.Verify` checks the complete package without changing files. It reports
missing or changed generated files and unexpected entries. Standard tool cache
directories (`ts/node_modules`, `kotlin/.gradle`, `kotlin/.kotlin`, `kotlin/build`,
`swift/.build`, and `swift/.swiftpm`) are ignored during verification and cleared
during generation. Generated `.gitignore` files exclude these caches from Git.

Run `make test-deps` to install pinned TypeScript, Kotlin, Swift (on Linux),
and JVM libraries in the ignored `.test-deps` directory. The installer needs
Java, Node/npm, Python 3, curl, GnuPG, tar, and unzip. Swiftly reports any missing system libraries.
If initial Swiftly setup fails while importing GPG keys on a minimal Linux
installation, install the `gpg-agent` package before retrying.
On Ubuntu, install `libcurl4-openssl-dev` before running the installer;
CI installs this package before `make test-deps`.
`make test` installs missing dependencies, sets the compiler paths and Kotlin
classpath, and runs the complete suite without the Go test cache. Kotlin compiler
and runtime versions are owned by `kotlin-dependencies.json`, which supplies both
the generated package manifests and the test installer. The Swift
transport fixture runs on Linux.

Generated-output tests compare complete results with golden files in
`testdata/golden`. To update expectations after an intentional output change:

```sh
make update-golden
git diff -- testdata/golden
```

Review the golden diff, then run `make test`.

`make update-golden` uses the same installed compilers and runtime dependencies
as `make test`. The complete typed-error SDK fixture compiles its generated
TypeScript, Kotlin, and Swift clients and types alongside the golden comparisons.
